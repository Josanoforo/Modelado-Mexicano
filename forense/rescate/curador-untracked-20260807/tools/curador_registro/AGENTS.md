# Curador del Registro Demanda-Universe

Estas reglas aplican a todo este directorio.

- Procesar exactamente una necesidad N1-N33 por invocación del trabajador.
- No editar el repositorio de entrada, el mapa ni una lectura adjudicada.
- No escribir parámetros en MILPA ni seleccionar piloto, vertical, champion o modelo.
- No confirmar relaciones sin evidencia explícita de apertura para la fuente y necesidad.
- Conservar negativos y conflictos; nunca degradarlos silenciosamente.
- Espejo, sesión, Fable y borradores son contexto, nunca autoridad sobre main.
- Las salidas generadas deben vivir fuera del repositorio o en una ruta ignorada.
