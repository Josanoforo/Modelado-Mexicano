Supplementary material for “Global evidence on economic preferences” (QJE, 2018)
On this site we provide material that was used to produce the results described in the paper.
  • Article
  • Web appendix
  • Do-files (Stata)
    We provide the statistical code that we used to generate the results in the paper above.
    • Note: In order to run the do-files you need data from different sources.
    • To generate the country level results: The country level data consist of data from the GPS that can be downloaded here and data from additional data sources that are described in the web appendix. You can download the merged country level dataset (GPS country plus additional measures) here.
    • The Stata-code to replicate the country level results using the merged country level dataset can be downloaded here.

    • To generate the individual level results: The individual level data consist of data from the GPS that can be downloaded here. This dataset contains the six individual preference measures, country identifiers, subjective math score, interview date, language, and personal identifiers. These personal identifiers allow you to link the GPS individual dataset with the 2012 Gallup World Poll microdata set. The latter provides additional data on the individual level. See the FAQ on how to merge these datasets.
    • The Stata-code to replicate the individual level results can be downloaded here. Note that running these files requires merging the GPS individual dataset with the 2012 Gallup World Poll microdata set.
