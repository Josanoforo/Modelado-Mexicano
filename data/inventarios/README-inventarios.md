# Inventarios ciegos de fuentes — 30/jul/2026

Diez ejercicios de catalogación, uno por dominio, compilados sin consultar el
pre-registro ni el modelo. Eso es lo que los hace útiles: no fueron a buscar la
fuente que el programa necesitaba, fueron a ver qué existe.

**Qué NO contienen, por diseño:** resultados, nombres de variables, reactivos,
valoraciones de calidad. Son catalogación, no exploración de estructura.
Por ADR-46 leerlos **no contamina** una sesión para pre-registrar.

**Convención heredada:** "No verificado" marca lo que no se confirmó con
búsqueda en la sesión de compilación. Se conserva tal cual; no se rellena.

**Procedencia:** compilados en sesiones de chat y traídos aquí desde el espejo
del proyecto, sin sello de commit de origen. Tipo (3) hasta este commit; a
partir de aquí son tipo (1) y `catalogo-fuentes-v2_0.md` se deriva de ellos
(el 11º inventario, `inventario_fuentes_clase-fuente-mexico.md`, se sumó el
4/ago/2026 — Encargo AA. `catalogo-fuentes-v1_0.md` quedó borrado por convención de versionado ADR-36; la cita se actualiza aquí, no se congela: es una referencia al catálogo vigente).

**No se editan a mano para "corregir" el catálogo.** Si una fuente falta o está
mal, se corrige aquí y se regenera el catálogo — nunca al revés.
