Las siete citas en negritas que T16 vigila (`estado-programa:129,221`, `gobernanza:764,856,1274,1387,1393`) se resincronizaron `131→130` dentro del propio `ADR-89`. Tras eso, quedó **una** entrada ROJO que ninguna edición de contenido explicaba:

## §1 · Causa raíz

```
$ sed -n '1330,1332p' tests/check.py   # antes del fix
def _baseline_key(msg):
    msg = re.sub(r":\d+ ", ": ", msg, count=1)
    return _T22_EDAD_VARIABLE.sub("(N días)", msg)
```

`T16` emite, para `gobernanza:1106` y `:1136`, un mensaje que incrusta el `real_fail`/`real_warn` **vigente** (código en `tests/check.py`, función `t16_...`, ~línea 601): `f"{rel(p)}:{i} declara {fd} FAIL · {wd} WARN vigente; la corrida real da {real_fail} FAIL · {real_warn} WARN"`. `_baseline_key` normalizaba el número de línea y la antigüedad de `T22`, pero no ese sufijo — así que el mensaje de esas dos líneas cambia de texto cada vez que el WARN real de la suite se mueve, **por cualquier causa**, y deja de coincidir con lo que `tests/baseline.json` tiene congelado. `tests/baseline.json` (congelado por `ADR-88`, mismas horas, con `real_warn=131`) tenía la clave vieja; al bajar a 130, deja de calzar.

Mismo género de defecto que `_T22_EDAD_VARIABLE` ya resolvió para `T22` (comentario en `tests/check.py:1312-1327`, `ADR-88`) — un valor que cambia sin que el archivo citado cambie un byte, incrustado en la clave de comparación en vez de excluido de ella.

## §2 · La corrección

```python
_T16_REAL_SUFIJO = re.compile(r"la corrida real da (\d+ FAIL · )?\d+ WARN")

def _baseline_key(msg):
    msg = re.sub(r":\d+ ", ": ", msg, count=1)
    msg = _T22_EDAD_VARIABLE.sub("(N días)", msg)
    return _T16_REAL_SUFIJO.sub("la corrida real da N WARN", msg)
```

Cubre las dos variantes que `T16` produce (`m1`, con `FAIL · WARN`; `m2`, solo `WARN`) con un único patrón, grupo opcional. Aplicada **después** de las dos normalizaciones existentes, sin tocarlas.

1. Mismo `declara` (histórico), distinto `real` → misma clave — el bug se cierra: `gobernanza:1106`/`:1136` dejan de romperse cuando el WARN real cambie mañana, pasado, o dentro de tres PRs, por cualquier motivo.
2. Distinto `declara` (un hallazgo genuinamente nuevo en la misma línea) → clave distinta — `T16` no queda ciego a una regresión real.
3. Distinto archivo/línea, mismo `declara` → clave distinta — sin colisión falsa entre citas distintas que digan lo mismo.
4. Un mensaje que no trae `"la corrida real da"` (la variante de otro test) → sin tocar — el patrón no sobre-matchea fuera de su dominio.
