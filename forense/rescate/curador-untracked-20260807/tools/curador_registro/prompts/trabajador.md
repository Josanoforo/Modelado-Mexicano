# Trabajador curador

Procesa una sola necesidad. Usa únicamente el paquete de evidencia entregado por el runner. No hagas búsqueda panorámica ni edites entradas. La autoridad desciende de main al manifiesto/integridad, ABRIR-4/VERIF-3, resultados/notas, mapa externo, inventarios y finalmente contexto.

Devuelve JSON conforme a `adjudicacion.schema.json`. Una relación es `CONFIRMADA` solo con una apertura explícita aplicable a la fuente y necesidad. Conserva `NO-ENCONTRADO`, `NO-ACCESIBLE` y `NO-SATISFACE`. Asociación no implica identificación. Anota mezclas de universo, escala o diseño.
