# ADR-260927-GEN2-TUBERIA-CI-TIEMPO-2-a387-01 · la derivación sale del check y se publica por trozos

EJECUTADO: el paso de derivados sale de `guardias` a un job `derivados` propio (push a main, manual, nocturno) fuera de `needs` de `check`; `check` conserva nombre y tests. El lote de replay se publica por trozos de 20 (`lote_desde_asientos.py --trozo`, `registro --pospone`), un commit `[deriva]` por trozo, presupuesto 900 s; lo no publicado sigue pendiente y el run siguiente lo retoma. Equivalencia medida sobre los 121 pendientes reales: lote entero == tres trozos, byte a byte. Guardia `LOTE-PENDIENTE` (umbral 60) con NC automática. Premisa SUPUESTO caída: `registro --lote` no era incremental para filas nunca publicadas. Cero mediciones, cero adopciones. Drenaje y run de main citados: tras el merge. Nota: `forense/notas/nota-2026-09-27-gen2-tuberia-ci-tiempo-2.md`.
